## 6. 推荐部署顺序与服务器验证

1. 停服，在游戏目录之外备份本次涉及的原文件及旧卸载插件。
2. 上传增量包中的 `addons`、`cfg` 内容到服务器 `left4dead2` 的相同位置，共 41 个运行文件。
3. 移走第 4 节列出的旧 `predictable_unloader.smx`。如有仓库之外的自定义模式，适配其退出配置。
4. 完整重启服务器，再进入普通 ZoneMod；本次涉及底层依赖和模式管理器，使用完整重启进行验证。
5. 在服务器控制台执行下列查询，检查插件与扩展是否成功加载：

```text
sm plugins list
sm exts list
pm_protect_list
```

`pm_protect_list` 应包含管理器自身、`left4dhooks.smx` 与 `fixes/command_buffer.smx`。进入比赛后重点检查 Confogl 2.6.0、Left4DHooks 1.174、ReadyUp 10.2.9-nb1 和 4 个新增修复插件为运行状态，没有旧卸载器。

服务器空闲时测试模式切换：

```text
sm_forcematch zonemod
sm_forcechangematch zonemod_dv
sm_cvar dv_enable
sm_cvar l4d_ready_cfg_name
sm_forcechangematch zonemod
sm_resetmatch
```

如果已经在比赛模式中，直接从 `sm_forcechangematch` 开始；`sm_forcematch` 用于当前未加载比赛模式的情况。DV 模式下 `dv_enable` 应为 1，准备面板模式名应完整显示中文。退出或切回普通 ZoneMod 后，确认 DV 规则关闭且模式插件正常恢复。模式切换会影响当前比赛，在测试服或空闲时操作。

再检查 `!exp`、`!mix`、大厅加入、旁观、暂停/恢复、Bot、上下半场和换图，并查看 SourceMod 日志中是否出现 `Unknown command`、缺失 native、签名或插件加载错误。
